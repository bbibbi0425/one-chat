# one-chat

초대 링크와 닉네임으로 시작하는 9시간 채팅방.

## 개발 범위

1. 프로젝트 기반: React, TypeScript, Vinext, Cloudflare Workers / D1
2. 초대 링크, 방 생성·입장, 생성 시점부터 9시간 만료
3. 브라우저에서 메시지 암호화, 서버에는 암호문 저장
4. 자동 대화 동기화, 연결 복구, 만료 안내
5. 권한·암호화·만료 검증 및 실행 문서

회원 가입과 파일 첨부는 제공하지 않습니다. 회사 기기의 모니터링이나 네트워크 접속 기록을 숨기는 서비스가 아닙니다.

현재 저장소는 개발 중이며 아직 배포하지 않았습니다.
